# Advanced_AI_Project
Repo for our advanced AI class that creates modes for threat intelligence

# Overview:
### This project uses machine learning and deep learning to create a phishing detector model. It compares results against the full dataset and using feature importance to omit variables to address what are the minimum variables needed to create a phishing detector with elements that cannot be spoofed by malicious actors. 

# Dependencies
### Dependencies used include Sklearn, PyTorch, Tensorflow, Pandas, Numpy, Seaborn and Matplotlib

# Instructions:
### Make sure you have the dependencies installed via pip. If you are using google colab torch_geometric will need to be reinstalled after each session. The results should be within a reasonable amount of each other as AI outputs can vary from run to run.
